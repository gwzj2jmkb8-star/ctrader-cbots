# AlgoTrader - MRSB & DATR Channel

**Description**: Improved MRSB and DATR Channel trading bot

## Overview
This is an advanced cTrader cBot that combines improved implementations of:
- **MRSB** (Multi-Range Support Breakout) - Support/resistance-based breakout strategy
- **DATR** (Dynamic ATR) Channel - Adaptive channel trading using dynamic Average True Range

## Features
- Multi-Range Support Breakout detection
- Dynamic ATR channel calculation
- Adaptive zone identification
- Advanced technical analysis
- Real-time signal generation
- Risk management integration

## Main Files
- `datr_regime_channel_system.pine` - DATR channel core system
- Supporting indicators and strategies

## Strategy Components

### MRSB (Multi-Range Support Breakout)
- Identifies key support and resistance levels
- Detects breakout opportunities
- Multi-range analysis for confirmation

### DATR Channel (Dynamic ATR Channel)
- Uses Dynamic ATR for adaptive channel width
- Market regime identification
- Zone-based trading signals
- Volatility-adjusted parameters

## Performance
- Improved win rate with combined approach
- Better risk-adjusted returns
- Adaptive to market conditions
