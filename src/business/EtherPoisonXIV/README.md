# EtherPoisonXIV

This directory is the structured business unit for the EtherPoisonXIV implementation.

## Purpose

The package contains the operational runtime, supporting business documentation, and readiness checks for a single cTrader strategy domain. It is intentionally organized to separate:

- source implementation
- operational evidence
- deployment assets
- documentation and provenance

## Expected structure

```text
src/business/EtherPoisonXIV/
├── README.md
├── EtherPoisonXIVBusiness.csproj
├── src/
├── docs/
├── ops/
├── infra/
├── deploy/
├── scripts/
├── tests/
└── evidence/
```

## Documentation

The project-specific documentation should be retained here and kept aligned with the runtime and deployment artifacts.
