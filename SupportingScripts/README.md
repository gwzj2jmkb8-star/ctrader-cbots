# Supporting Scripts & Indicators

This directory contains supplementary Pine Script indicators and utility scripts that support the main cBot projects.

## Available Indicators

### Adam Indicators
- `Adam_Offensive_Rapid_Expansion.pine` - Aggressive expansion indicator
- `Ichimoku_Time_Theory_Adam_Oscillator_Companion.pine` - Adam oscillator paired with Ichimoku

### Ichimoku & FVG Strategies
- `Ichimoku_Time_Theory_Rapid_FVG_Area_Strategy.pine` - FVG area identification
- `Ichimoku_Time_Theory_Rapid_FVG_Area_Strategy(6).pine` - Enhanced FVG variant
- Combined Ichimoku time theory with Fair Value Gap analysis

### Enterprise Strategies
- `VITCO_Enterprise_Strategy_v7_2_Signals.pine` - Enterprise-grade strategy signals

## Integration
These indicators can be used:
- As standalone trading signals
- To enhance main cBot strategies
- For confirmatory analysis
- In combination with multiple timeframes

## Usage
Each Pine Script file can be imported into TradingView or adapted for cTrader platform.
